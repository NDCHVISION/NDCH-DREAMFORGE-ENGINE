# FREQ track sources

One folder per track, named like its post kit file (`001_I_LOVE_MYSELF`):

- `lyrics.txt`: the lyric sheet as written, one sung line per line. The QC gate checks the captions against it word for word.
- `captions_full.ass`, `captions_short.ass`: the burnt-in captions for each cut (1080×1920).

FREQ 001's lyric sheet was rebuilt from its released captions. From 002 on, paste the original sheet in first.

# NDCH artifacts

Artifact symbols: one artful image per reel, made before or alongside it. They
continue NDCH's original practice of frequency-inspired art and its symbolism,
so each one is a representation of the reel, not a frame from it. Kept here for
reference and future covers.

Not read by the engine.

Name files `<posting number>_<TITLE>_artifact.<ext>`. The posting number is the
public one (FRAMES posts as 024), not the engine file ID (NDCH_030).
